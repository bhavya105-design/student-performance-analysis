# Student Performance Analysis | Data Analyst Project

### 📊 Project Overview
Analyzed the relationship between student attendance and exam performance to provide actionable insights for academic improvement.

### 🔍 Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Excel
- GitHub

### 📈 Key Insights
- Students with >75% attendance scored 40% higher on average
- Positive correlation (r=0.85) between attendance and marks
- Identified at-risk students with low attendance
